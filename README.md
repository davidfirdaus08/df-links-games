### ✨ Features

- 🎯 **No registration** — Just play, instantly fun
- 📱 **Responsive** — Play on mobile, tablet, or desktop
- 🌍 **Multi-language** — English, Indonesian, Español, 日本語, 中文, 한국어, Русский
- 🏆 **Online leaderboard** — Compete with players worldwide
- 🎵 **Sound effects** — Audio via Web Audio API (no audio files)

**Color Rush:** Watch target color → Tap matching color as fast as possible → Build combos → Wrong = combo resets

**Tap Rush:** Watch indicator sweep → Tap when in green zone → Closer to center = more points → Level up = zone shrinks

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** PHP Native
- **Database:** MySQL + PDO
- **3D Engine:** Three.js (Veyndao)
- **No framework** — Pure vanilla code
